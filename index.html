Nametag Generator

Quickly generate custom WCA competition nametags using Google Slides.

  • Fully customizable Google Slides template.
  • No software installation required.
  • Pre-formatted CSV generator with many quality of life features.
  • Supports single sided or double sided nametags.
Printing formats supported
3x3 grid (NorCal)
  • The generated PDF is the same size as your provided PDF, with each nametag sized down to fit in a 3x3 grid
  • Fits 3x4 in nametag sleeves when your provided PDF is sized to letter paper.
2x4 grid (SoCal)
  • The generated PDF is letter size, with the nametags arranged at the center of the page leaving a border around them.
  • Fits 2.25x3.5 in nametag sleeves when your provided PDF pages are sized to 2.3x3.5 in.
This tool is built to match the workflow used by West Coast Cubing organizers. If any features are missing, reach out to Hamza Hafeez.
Disclaimer: this tool was built largely with AI-generated code, so please sanity-check the output.

Steps

  1. Go to the tab and download the CSV.
  2. Create a Google Drive folder, upload the CSV there, and open it as a Google Sheet.
  3. Copy a design template from this template folder and paste it into your folder.
  4. Edit the template freely in Slides. To add a CSV field, add {{fieldname}} matching a column header from the spreadsheet. You may change the page dimensions but the defaults are already set to whats described above. Keep both slides for a double sided tag, or keep only one slide for a single sided tag.
  5. In your copied Slides file, open the Nametag Generator menu in the top bar and click Run Merge (refresh if not visible). Reload your page if you can't see it. It will ask for some details and then create a new slideshow for your nametags in around 30 seconds. Open the slideshow in a new tab.
    You'll see a "Google hasn't verified this app" warning. Click Advanced, then Go to nametag_generator (unsafe). This is a small standalone script with no external dependencies. It only reads the data sheet and edits the copy of the slide it creates, and does not touch anything else in your Drive.
  6. Double check all the nametags look okay. You may need to do manual adjustments (changing font size). You can also change the design for delegates or organizers.
  7. In the File menu, choose Download, then PDF Document.
  8. Go to the tab and download the generated PDF.
CSV Specifications
  • Orders competitors alphabetically, split into returners and newcomers.
  • Splits the name into first name, last name, and localized name for flexibility in design.
  • WCA ID shows Newcomer for first time competitors.
  • Adds a stage letter prefix to group numbers when the competition has more than one stage.
  • Also generates rows for delegates and organizers with no listed tasks.
